Bloc 01 / 01 · Le point de départ

Des données à une première réponse.

Tableau est un logiciel de visualisation de données. On lui connecte un fichier, puis on construit des graphiques en déplaçant ses champs dans l’espace de travail.

Notre question de départ

Une petite boutique veut savoir quelle catégorie de produits réalise le plus de ventes. À la fin du bloc, vous saurez où trouver les données et où construire la réponse.

Objectif

Installer Tableau Public, reconnaître les principales zones du logiciel et produire une vue simple. Aucun code ni connaissance préalable de Tableau n’est nécessaire.

  • Lancer l’application sur son ordinateur.
  • Distinguer source de données, feuille, tableau de bord et classeur.
  • Repérer Données, Lignes, Colonnes, Filtres et Repères.
  • Ouvrir un CSV et obtenir trois barres vérifiables.

Résumé général

Le fichier fournit les données. La feuille permet de les représenter. Le tableau de bord rassemble des vues. Le classeur conserve votre travail. Nous commencerons avec une seule feuille.

Durée indicative : 75 à 90 minutes, dont 15 à 20 minutes d’installation. Prévoir un ordinateur Windows ou Mac, Internet pour le téléchargement et, si nécessaire, l’aide du service informatique.

Bloc 01 / 02 · Installer Tableau

Un logiciel prêt pour la séance.

Pour ce parcours, utilisez Tableau Desktop Public Edition, généralement affiché comme Tableau Public. Cette application gratuite convient à nos fichiers d’entraînement. Si Tableau Desktop est déjà installé par votre établissement, vous pouvez suivre les mêmes manipulations de base.

Télécharger Tableau Public ↗Vérifier la compatibilité ↗

Sur la page des caractéristiques, consultez la section « Tableau Public ». Vérifiez votre système, la mémoire et l’espace disponible pour la version téléchargée. Sous Linux ou ChromeOS, faites prévoir un poste Windows/Mac pour suivre ce bloc dans l’application.

Installation sous Windows

  1. Ouvrez la page de téléchargement officielle. Renseignez le formulaire s’il est proposé, puis récupérez l’installateur Windows.
  2. Dans Téléchargements, lancez le fichier .exe. Vérifiez que l’installateur annonce Tableau Desktop Public Edition.
  3. Acceptez les conditions pour poursuivre et suivez l’assistant. Une autorisation administrateur peut être demandée.
  4. Lancez Tableau Public depuis le menu Démarrer. Terminez l’écran d’enregistrement s’il apparaît.

Installation sous macOS

  1. Ouvrez la page officielle et téléchargez l’installateur Mac. Si plusieurs variantes sont proposées, choisissez celle correspondant à votre processeur : Intel ou Apple Silicon. Vous pouvez le vérifier dans  → À propos de ce Mac.
  2. Ouvrez le fichier .dmg, puis double-cliquez sur le paquet .pkg qu’il contient.
  3. Suivez l’assistant, acceptez les conditions pour poursuivre et autorisez l’installation si votre ordinateur le demande.
  4. Ouvrez Tableau Public dans Applications. Terminez l’écran d’enregistrement s’il apparaît.
Point de contrôle

L’application est ouverte et propose de se connecter à un fichier. Si vous voyez une demande de clé de licence, vérifiez que vous avez téléchargé l’édition Public. Si l’installation est bloquée sur un poste d’école, sollicitez le service informatique.

Faut-il créer un compte ?

Le formulaire de téléchargement et le profil Tableau Public ne sont pas la même chose. Un profil sert notamment à publier en ligne. Pour ce bloc, nous travaillons dans l’application et enregistrons localement avec une version récente.

Enregistrer et publier sont deux actions différentes.

Les versions récentes de Tableau Public permettent la sauvegarde locale. Une publication sur Tableau Public rend le classeur et les données publiées accessibles au public. Utilisez uniquement le jeu fictif fourni pour les exercices.

Bloc 01 / 03 · Ouvrir des données

Le fichier, avant le graphique.

Un CSV est un fichier texte organisé en lignes et en colonnes. Notre boutique fictive fournit 12 ventes : chaque ligne représente une commande, chaque colonne une information.

Télécharger les 12 ventes ↓
  1. Enregistrez ventes_decouverte.csv dans un dossier que vous retrouverez.
  2. Sur l’accueil de Tableau, dans Se connecter, choisissez Fichier texte (Text File). Sélectionnez le CSV.
  3. L’écran Source de données apparaît. Si le fichier n’est pas déjà placé dans la zone centrale, faites-le glisser depuis la gauche.
  4. Vérifiez les cinq colonnes ci-dessous et les 12 lignes. L’aperçu permet de contrôler l’import avant l’analyse.
  5. Cliquez sur Feuille 1, en bas, pour entrer dans l’espace de création.

Tout apparaît dans une seule colonne, ou le type est incorrect ?

Dans le menu de la table, ouvrez les propriétés du fichier texte et vérifiez le séparateur : notre fichier utilise la virgule et l’encodage UTF-8. La première ligne contient les noms de colonnes. Pour corriger un type, cliquez sur l’icône à côté du nom du champ et choisissez Date ou Nombre (entier).

Les noms des champs du fichier n’ont volontairement pas d’accents : retrouvez exactement « Region » et « Categorie » dans Tableau.

Bloc 01 / 04 · Les mots à connaître

Chaque élément a un rôle.

Le contenant

Classeur

Le document Tableau qui rassemble votre travail. Exemple : le classeur « Découverte boutique » contient vos feuilles et, plus tard, un tableau de bord.

Les informations

Source de données

La connexion aux données utilisées dans l’analyse. Ici, c’est notre CSV. On y vérifie la structure et les types avant de construire une vue.

Une vue

Feuille de calcul

L’espace où l’on crée un graphique ou une table. Exemple : « Ventes par catégorie ». Elle répond à une question précise.

Plusieurs vues réunies

Tableau de bord

Une page qui assemble plusieurs feuilles pour les consulter ensemble. Exemple futur : ventes par catégorie et par région.

Une histoire (Story) organise des feuilles ou des tableaux de bord en une succession de points pour guider une présentation. Il suffit de savoir la reconnaître pour l’instant.

Dimension et mesure

Une dimension sert à répartir les données en groupes : Categorie donne Accessoires, Informatique et Mobilier. Une mesure est une quantité que l’on peut agréger : Ventes est ici un montant à additionner.

La question qui aide

« Les ventes par quoi ? » → par catégorie : dimension.
« Combien de ventes ? » → un montant : mesure.

Bleu signifie discret et vert signifie continu. Ce n’est pas une règle « bleu = texte, vert = nombre ». Nous approfondirons cette distinction dans la suite du parcours.

Bloc 01 / 06 · Première manipulation

Quelle catégorie vend le plus ?

Nous allons construire la réponse ensemble. Gardez Tableau ouvert à côté de ce support. La vue attendue est un diagramme de trois barres horizontales.

  1. Dans Feuille 1, repérez Categorie dans Données et glissez ce champ sur Lignes.
  2. Glissez Ventes sur Colonnes. Tableau affiche normalement SOMME(Ventes) ou SUM(Ventes).
  3. Si nécessaire, choisissez le type Barres dans la fiche Repères.
  4. Pour voir les montants, glissez aussi Ventes sur Étiquette dans Repères. Le champ peut être utilisé à plusieurs endroits.
  5. Faites un clic droit sur l’onglet Feuille 1 (ou Ctrl-clic sur Mac), choisissez Renommer et saisissez « Ventes par catégorie ».
  6. Dans Fichier → Enregistrer sous, enregistrez le classeur sur l’ordinateur sous « Decouverte_Tableau ». Si le format .twbx est proposé, choisissez-le pour regrouper le classeur et ses données locales. Conservez aussi le CSV.
Résultat attendu

Informatique arrive en tête.

Les quatre commandes de chaque catégorie sont regroupées en une barre. Nous obtenons 3 repères pour 12 lignes de données.

Accessoires360 €
Informatique510 €
Mobilier450 €

Comprendre l’addition

SOMME(Ventes) additionne les montants des lignes de chaque groupe. Pour Informatique : 120 + 180 + 90 + 120 = 510 €. Chaque nombre est le montant d’une commande ; 510 € est le total de la catégorie. Le total des trois barres est 1 320 €.

Pourquoi ne voit-on pas les 12 commandes ?

La dimension Categorie définit trois groupes. La mesure Ventes est additionnée à l’intérieur de chacun. Vous regardez donc des totaux par catégorie, et non une barre par commande.

Un premier résultat, une conclusion mesurée.

Informatique a le montant de ventes le plus élevé dans ce petit fichier. Cela ne dit rien sur le bénéfice : aucun coût ni aucune marge ne sont fournis.

Bloc 01 / 07 · Erreurs fréquentes

Un résultat inattendu ? Revenez aux repères.

Trois valeurs égales à 4Le champ est peut-être agrégé en Nombre (COUNT). Dans le menu de la pastille Ventes, choisissez Mesure → Somme.
Ventes apparaît comme du texteRetournez dans Source de données et choisissez le type Nombre (entier) pour Ventes.

La vue est videVérifiez que vous êtes dans une feuille, avec les champs sur les étagères et sans filtre excluant toutes les données.

Bloc 01 / 08 · À vous de jouer

Trois exercices pour prendre la main.

Exercice 01 · Guidé · 5 min

Retrouver son chemin

Objectif : distinguer préparation des données et construction d’une vue. Prérequis : le CSV est connecté.

Énoncé : ouvrez Source de données, relevez le nombre de colonnes, puis revenez à la feuille et montrez Données, Lignes, Colonnes et Repères. Expliquez à votre voisin où vérifier un type et où créer un graphique.

Contraintes : ne modifiez pas le fichier. Livrable : une courte explication orale et les zones désignées à l’écran. Réussite : cinq colonnes reconnues, quatre zones retrouvées et les deux écrans correctement distingués.

Indice 1

Commencez par les onglets tout en bas.

Indice 2

Les champs apparaissent à gauche de la feuille ; les étagères sont au-dessus de la vue.

La correction détaillée sera présentée ou transmise séparément par le formateur.

Exercice 02 · Autonome · 8 min

Recréer la vue sans le pas-à-pas

Objectif : associer une dimension et une mesure. Prérequis : la première manipulation a été réalisée.

Énoncé : avec le bouton Nouvelle feuille de calcul en bas, créez une seconde feuille « Ma première vue ». Reproduisez le montant total des ventes par catégorie et affichez les montants.

Contraintes : trois barres horizontales, aucun filtre et agrégation Somme. Livrable : une feuille nommée dans le classeur enregistré. Réussite : 360 €, 510 € et 450 €, associés aux bonnes catégories.

Indice 1

« Par catégorie » indique le champ qui crée les groupes.

Indice 2

Pour des barres horizontales, placez les catégories sur Lignes et les montants sur Colonnes.

La correction détaillée sera présentée ou transmise séparément par le formateur.

Exercice 03 · Diagnostic · 7 min

Pourquoi les trois barres valent-elles 4 ?

Objectif : expliquer une agrégation incorrecte. Prérequis : comprendre la première vue et avoir lu les erreurs fréquentes.

Énoncé : un collègue a placé Categorie sur Lignes et NOMBRE(Ventes), ou COUNT(Ventes), sur Colonnes. Son graphique montre 4 pour chaque catégorie. Expliquez ce qu’il mesure puis indiquez la correction pour retrouver les montants. Vous pouvez reproduire le problème via le menu de la pastille.

Contraintes : gardez les 12 lignes du CSV. Livrable : deux phrases d’explication et la vue corrigée. Réussite : distinguer nombre de valeurs et montant total, puis retrouver les trois totaux.

Indice 1

Chaque catégorie comporte quatre commandes.

Indice 2

Comparez les mots Nombre et Somme dans le menu de la mesure.

La correction détaillée sera présentée ou transmise séparément par le formateur.

Bloc 01 / 09 · Le fil rouge

Le carnet de bord de la boutique.

Contexte et utilisateurs

Dans notre cas fictif, la responsable d’une boutique souhaite consulter ses ventes sans relire chaque commande. Vous préparez son classeur d’analyse.

Problème à résoudre

Transformer une liste de commandes en une réponse lisible : quelle catégorie représente le plus de ventes ?

Fonctionnalités cibles

Pour ce premier bloc : connecter le fichier, vérifier les champs et montrer les ventes par catégorie. Dans la suite du cours, ce même classeur pourra accueillir d’autres vues et un tableau de bord.

Modèle de données et organisation attendue

Une seule table de 12 commandes, cinq champs et aucun rapprochement de tables. Gardez le CSV et le classeur « Decouverte_Tableau » dans un même dossier de travail. La feuille « Ventes par catégorie » constitue la première vue réutilisable.

Jalon de ce blocNotions et productionValidation / point de vigilance
1 · ImporterConnexion et types : une source prête12 lignes, 5 champs ; éviter un import en une seule colonne
2 · ReprésenterDimension, mesure et étagères : une feuille nommée3 barres ; vérifier Somme plutôt que Nombre
3 · Conserver et expliquerClasseur et sauvegarde : un fichier localRouvrir la vue et identifier Informatique à 510 € ; ne pas confondre ventes et bénéfice

Livrables et critères de validation

Un classeur enregistré, le CSV conservé et une phrase de conclusion : « Dans ce fichier, Informatique réalise le plus de ventes, avec 510 €. » Le classeur doit se rouvrir avec la vue attendue. Si un chemin de source est demandé, reconnectez le CSV conservé.

Extension facultative

Recréez une feuille en remplaçant Categorie par Region. Expliquez ce qui change dans les groupes, et pourquoi le total global reste 1 320 €.

Cas d’usage réels : où retrouve-t-on cette démarche ?

Ces situations sont des exemples métier, sans entreprise nommée ni résultat chiffré attribué.

  • Commerce : une enseigne compare ses familles de produits ; une vue des ventes rend les écarts lisibles et aide à préparer une réunion commerciale.
  • Logistique : un transporteur compare les délais par site ; un graphique permet de repérer où approfondir l’analyse.
  • Formation : un organisme suit les inscriptions par session ; une vue synthétique aide à adapter les capacités d’accueil.

Questions de révision

Répondez d’abord à voix haute, puis ouvrez les réponses.

1. Où vérifier que Ventes est numérique ?

Dans Source de données, à l’aide de l’icône de type du champ Ventes.

2. Pourquoi trois barres pour douze commandes ?

Les commandes sont regroupées en trois catégories et leurs montants sont additionnés.

3. À quoi servent Lignes et Colonnes ?

À organiser la vue. Ici, les catégories sur Lignes définissent les groupes et la mesure sur Colonnes fournit l’axe horizontal.

4. Où modifier les couleurs et les étiquettes ?

Dans la fiche Repères, avec Couleur et Étiquette.

5. Un fichier enregistré localement est-il publié ?

Non. La sauvegarde locale et la publication sur Tableau Public sont deux opérations distinctes.
