Comment utiliser cette bibliographie

Les vidéos de formation officielles repérées sont principalement en anglais. Les vidéos actuelles sont privilégiées pour apprendre l’interface. Les ressources d’archive sont signalées : Tableau précise qu’elles montrent des versions qui ne sont plus prises en charge. Elles servent à illustrer un concept, pas à suivre les menus au pixel près. Les vidéos Tableau Cloud/Server ne sont pas mélangées aux parcours Desktop lorsqu’elles montreraient une interface différente.

La sélection couvre le catalogue officiel des vidéos de formation gratuites et son archive, en retenant les sujets présents dans les cours. Elle ne recense pas les webinaires marketing, les vidéos d’administration ni les produits absents du programme.

Modèle des données

Analyse de données reliées · SQL et relations

  • Combining Data in Tableau Desktop ↗ 4 min · actuelle
    Illustration générale du rapprochement de données. À compléter avec la distinction du cours entre relation logique Tableau et jointure physique.
  • Relationships ↗ Archive officielle · rechercher le titre
    Explique les relations entre tables qui n’ont pas le même niveau de détail. C’est la vidéo d’archive la plus proche de notre modèle Orders–Returns.
  • Join Types with Union ↗ Archive officielle · rechercher le titre
    Présente les jointures gauche, droite, interne et externe. L’interface est ancienne ; gardez surtout l’effet de chaque type de jointure.
Pas de vidéo SQL dédiée dans le catalogue de formation retenu.

Les vidéos repérées traitent de la modélisation ou des jointures dans Tableau ; elles n’enseignent pas directement SELECT, WHERE, GROUP BY ou l’écriture de SQL personnalisé. Pour ces notions, le chapitre reste la référence.
