Comment utiliser cette bibliographie

Les vidéos de formation officielles repérées sont principalement en anglais. Les vidéos actuelles sont privilégiées pour apprendre l’interface. Les ressources d’archive sont signalées : Tableau précise qu’elles montrent des versions qui ne sont plus prises en charge. Elles servent à illustrer un concept, pas à suivre les menus au pixel près. Les vidéos Tableau Cloud/Server ne sont pas mélangées aux parcours Desktop lorsqu’elles montreraient une interface différente.

La sélection couvre le catalogue officiel des vidéos de formation gratuites et son archive, en retenant les sujets présents dans les cours. Elle ne recense pas les webinaires marketing, les vidéos d’administration ni les produits absents du programme.

Fiche mémo · Champs calculés

Des formules pour répondre aux questions dans Tableau

Un champ calculé transforme une question métier en opération sur les données. Les exemples reprennent des champs utilisés dans le cours et le TP ; adaptez leurs noms à ceux affichés dans votre volet Données.

Avant d’écrire la formule : précisez ce que vous comptez ou mesurez, vérifiez le niveau d’une ligne, puis choisissez si le calcul se fait ligne par ligne ou après agrégation.

Question métier, formule et contrôle à faire
QuestionChamp calculé TableauDémarche et vigilance
Combien de commandes différentes ?COUNTD([Order Id])Compte chaque identifiant une fois. Vérifiez que la vue et les filtres couvrent le périmètre voulu.
Quel est le coût d’achat de cette ligne ?[Quantity] * [Unit Cost]Calcul ligne par ligne : quantité multipliée par coût unitaire.
Quelle marge brute cette ligne dégage-t-elle ?[Net Sales] - [Quantity] * [Unit Cost]Les ventes nettes intègrent déjà la remise dans le jeu du TP. On ne la déduit pas une seconde fois.
Quelle famille apporte la marge totale la plus élevée ?SUM([Marge brute])Créer d’abord la marge par ligne, puis la sommer avec la famille dans la vue.
Quel est le taux de marge par famille ?SUM([Marge brute]) / SUM([Net Sales])Ratio de sommes, à formater en pourcentage. Ne pas remplacer par la moyenne simple des taux par ligne.
Quelle part des commandes est associée à un retour ?COUNTD([Commande retournée]) / COUNTD([Order Id])Créer le champ conditionnel ci-dessous. Le dénominateur doit garder toutes les commandes ; ne filtrez pas toute la vue sur les seules commandes retournées.
Comment repérer une commande retournée ?IF [Returned] = "Yes" THEN [Order ID] ENDCette expression renvoie l’identifiant uniquement si la condition est vraie ; sinon le résultat est vide. Elle doit être utilisée avec les relations et les champs de la source correspondante.
Comment regrouper une date au mois ?DATETRUNC('month', [Order Date])Ramène les dates au début de leur mois. Pour une première courbe, le menu de la pastille Date suffit souvent ; ce calcul sert si un champ mensuel explicite est utile.
Comment classer les lignes selon leur marge ?IF [Marge brute] < 0 THEN "Marge négative" ELSE "Marge positive ou nulle" ENDUne condition IF … THEN … ELSE … END renvoie une étiquette. Vérifiez que le niveau ligne correspond bien à la question.

Lire et vérifier une formule

  1. Choisir le grain : une commande, une ligne de vente, un client ou une famille ?
  2. Calculer au bon niveau : les opérations sur les champs sans agrégation se font sur chaque ligne ; SUM, AVG et COUNTD agrègent ensuite les valeurs pour la vue.
  3. Contrôler : tester sur quelques lignes dont on peut refaire le calcul à la main, puis comparer les totaux avec le fichier ou une requête de référence.
  4. Interpréter : préciser l’unité, le périmètre des filtres et les limites de l’indicateur.
Attention aux retours et aux relations

Pour un taux d’unités retournées, il faut d’abord ramener les événements à une valeur par Line Id, puis diviser les unités retournées par les unités vendues. Une jointure physique brute peut répéter les lignes de vente et gonfler les ventes et les coûts. La formule ne corrige pas à elle seule une source dont le grain a été multiplié.
