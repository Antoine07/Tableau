De l’analyse à la correction

AnalyserRemettreRéactiverCorriger

Le formateur indique l’étude à réaliser selon l’avancement du groupe. Après la remise, un QCM de réactivation se fait sans support à la reprise suivante, avant la correction collective. Les études se réalisent dans Tableau ; aucun exercice Power BI ni Python n’est demandé.

Les rendus comprennent deux ou trois vues, leurs captures, un tableau de contrôle et une synthèse de dix lignes maximum. Le canal de remise est indiqué par le formateur. Le site ne collecte pas les fichiers.
